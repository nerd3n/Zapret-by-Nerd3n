# zapret by nerd3n

Python-приложение для Windows с отдельным окном, автоматическим определением провайдера и подбором стратегий [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) для YouTube и Discord. Текущий HTML/CSS-интерфейс работает внутри WebView2; отдельная вкладка браузера для обычного запуска не нужна.

Движок zapret и стратегии уже входят в комплект. Указывать путь к zapret или скачивать его отдельно не нужно. Провайдер и город заранее не назначаются: профиль для отчётов пуст, обнаруженная сеть показывается отдельно. Описание профиля Инфолинка сохранено в поставке как дополнительный справочный файл.

[Скачать из Releases](https://github.com/nerd-en/zapret-by-nerd3n/releases) · [Сообщить об ошибке](https://github.com/nerd-en/zapret-by-nerd3n/issues) · [Как выпустить релиз](docs/RELEASING.md)

**Версия 0.3.5 — предварительная.** Обновлён логотип и явно настроены значки работающего окна, EXE, установщика и ярлыков. [Изменения 0.3.5](docs/RELEASE_NOTES-v0.3.5.md).

Есть сеансовый запуск и установка выбранной стратегии как службы с автозапуском Windows. Автоподбор использует проверки Flowseal Standard: HTTP/1.1, TLS 1.2, TLS 1.3 и ping. Воспроизведение видео и голосовой чат необходимо проверить отдельно; эффективность на реальной линии Инфолинка пока не подтверждена.

## Возможности

- Запуск и остановка выбранной стратегии через интерфейс.
- Установка выбранной стратегии как службы Windows с запуском при включении компьютера.
- Определение оператора внешнего IP, ASN и приблизительного города при наличии данных.
- Автоматическое сравнение исходного подключения и всех 28 кандидатов при первом запуске.
- Повторная проверка выбранной стратегии перед автоматическим применением.
- Ручной выбор кандидатов и от одного до трёх повторов на каждый проверяемый адрес.
- Отмена проверки, таблица результатов, сохранение и скачивание JSON-отчётов.
- Обнаружение другой запущенной копии `winws`, чтобы не смешивать результаты.
- Две темы: графит с красным акцентом и тёмная с зелёным. Выбор сохраняется в браузере.

Приложение управляет своим сеансовым процессом `winws` и своей службой `ZapretByNerd3n`. Служба устанавливается отдельной кнопкой; первый запуск и автоподбор сами её не создают. Приложение не меняет hosts и системные настройки DNS.

## Требования

| Требование | Подробности |
| --- | --- |
| Система | Windows 10/11, x64 |
| Архитектура | Процессор x64; поставляемый драйвер не поддерживает Windows ARM64 |
| Права | Администратор для запуска `winws` и проверки стратегий |
| Окно приложения | Microsoft Edge WebView2 Runtime x64 и .NET Framework 4.8 |
| Сетевые проверки | Штатный `curl.exe` в Windows и доступ к интернету |
| Python | Для готового приложения не нужен; для исходников — Python 3.10+ |

Без прав администратора можно открыть интерфейс, определить оператора и посмотреть состояние службы. Для запуска движка, полного автоподбора и управления службой нужны повышенные права. Если WebView2 отсутствует, установите [Evergreen Runtime x64 с сайта Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). Python и библиотеки окна уже встроены в готовый EXE.

## Установка и запуск

### Установщик

1. Откройте [Releases](https://github.com/nerd-en/zapret-by-nerd3n/releases) и выберите версию. Если релиз ещё не опубликован, используйте сборку из исходников ниже.
2. В разделе **Assets** скачайте `Zapret-by-nerd3n-Setup.exe` и запустите его.
3. Выберите папку. По умолчанию используется `%LOCALAPPDATA%\ZapretByNerd3n`.
4. В конце установки оставьте включённым запуск приложения и подтвердите запрос Windows на повышение прав.
5. Откроется отдельное окно приложения; при первом запуске начнётся определение сети и подбор стратегии. Если служба уже установлена, новый подбор автоматически не запускается.

Установщик создаёт ярлык в меню «Пуск». Ярлык на рабочем столе предлагается отдельно. Для последующих запусков используйте установленный ярлык: он запрашивает необходимые права. Отмена запроса UAC не отменяет уже завершённую установку.

### Переносная версия

1. Скачайте `zapret-by-nerd3n-portable.zip` из **Assets**.
2. Распакуйте весь архив в папку, доступную для записи, например `C:\Tools\ZapretByNerd3n`.
3. Запустите `ZapretByNerd3n.exe` через **Запуск от имени администратора**.

Перемещайте всю папку целиком: рядом с EXE должны оставаться `bundle`, `profiles` и лицензии. Путь к комплекту вычисляется относительно приложения, а не текущей рабочей папки. Архив **Source code**, который создаёт GitHub, предназначен для разработки и не содержит собранного EXE оболочки.

### Адрес и завершение работы

По умолчанию интерфейс открывается в собственном окне размером 1400 × 900. Внутренний сервер использует `http://127.0.0.1:17841` и слушает только этот компьютер; открывать порт на роутере не требуется. Внешние ссылки открываются обычным браузером. Для разработки доступен отдельный режим `--browser`.

Закрытие окна крестиком или кнопка **Завершить приложение** останавливает локальный сервер и сеансовый движок. **Установленная служба продолжает работать после закрытия окна.** Остановить её или удалить автозапуск можно отдельными кнопками. При аварийном завершении оболочки её сеансовый `winws` останавливается через Windows Job Object. В дополнительном режиме `--browser` закрытие вкладки само по себе не завершает сервер.

### Обновление и удаление

Для обновления запустите новый установщик и выберите ту же папку. Начиная с 0.3.2, перед копированием он находит запущенное приложение из этой папки и запрашивает штатное завершение через локальный API `/api/exit`. Это позволяет закрыть и старую копию 0.2.0, работающую с повышенными правами. Для этого шага отдельный запрос UAC не нужен; собственный сеансовый движок останавливается вместе с приложением.

Установщик ждёт освобождения EXE и заменяемых файлов движка до 60 секунд. Начиная с 0.3.3, есть одно исключение: `bundle/bin/WinDivert64.sys` остаётся на месте, если его SHA-256 совпадает с драйвером в установщике. Загруженный драйвер Windows может удерживать этот файл после завершения приложения и его `winws`; переписывать идентичный файл не требуется.

Другой, изменённый или недоступный для чтения драйвер не получает этого исключения. Если заменяемые файлы остаются заняты или доступ к ним запрещён, обновление останавливается **до замены файлов** с объяснением. Завершите соответствующее приложение штатно и повторите установку; для остающегося загруженным другого драйвера может потребоваться перезагрузка Windows. Чужие процессы `winws` и общая служба WinDivert автоматически не останавливаются и не удаляются. Уже установленная наша служба продолжает использовать свою защищённую копию в Program Files.

Пользовательские списки, настройки, отчёты и выбранные `ACTIVE_*.bin` сохраняются; штатные файлы комплекта обновляются. Перед удалением программы завершите приложение через интерфейс.

Удаление доступно через параметры Windows и ярлык в меню «Пуск». Если установлена наша служба, деинсталлятор запросит повышение прав и сначала удалит её; при отмене UAC или если служба осталась зарегистрирована, удаление программы прерывается. Пользовательские данные могут остаться в папке приложения. Для переносной версии сначала нажмите **Удалить автозапуск**, если служба установлена, затем закройте приложение и удалите его папку.

## Автозапуск zapret

| Действие | Результат |
| --- | --- |
| Запустить | Временный процесс: работает до остановки или закрытия приложения |
| Установить с автозапуском | Устанавливает выбранную стратегию как службу, запускает её сейчас и при старте Windows |
| Запустить службу | Запускает ранее установленную службу |
| Остановить службу | Останавливает её сейчас; автоматический запуск при следующем старте Windows сохраняется |
| Удалить автозапуск | Останавливает и удаляет нашу службу и её выделенный комплект |

Выберите стратегию в **Обзоре**, проверьте её работу и нажмите **Установить с автозапуском**. Нужны права администратора. Если через приложение уже запущена сеансовая стратегия, оно остановит её перед установкой; при неудаче и отсутствии оставшейся службы попробует восстановить предыдущий процесс.

Используется диспетчер служб Windows, как в `service.bat`: автоматический тип запуска и прямой запуск `winws` с аргументами выбранной стратегии. Имя службы — `ZapretByNerd3n`. Она не зависит от открытого интерфейса или входа пользователя в систему. Комплект копируется в защищённую папку `%ProgramFiles%\ZapretByNerd3n-Service`; путь пользовательской папки не используется для запуска от LocalSystem.

Служба запускает `winws.exe` напрямую с полной командной строкой выбранной стратегии. В 0.3.4 исправлено чтение длинной команды, в частности ALT11: API `QueryServiceConfigW` ограничен буфером 8 КБ. При известных ошибках RPC 1734/1783 либо ошибке 122 с требуемым буфером больше 8 КБ приложение читает конфигурацию из реестра, проверяя защищённый ACL, ownership marker со схемой 1 и хеш команды. Само чтение не меняет запись службы. Текущее состояние и PID всегда запрашиваются у диспетчера служб Windows.

Если после прежней неудачной установки осталась остановленная наша служба, обновите приложение до актуальной версии (0.3.4 или новее), откройте его от имени администратора и нажмите **Запустить службу**. Приложение проверит принадлежность и защищённость службы и запустит сохранённую стратегию с прежней полной командой. После появления состояния «Работает» оно ещё 3 секунды проверяет, что процесс не завершился сразу после старта. При ошибке проверки владения или запуска показывается причина.

Пока служба установлена, сеансовый запуск и перебор стратегий заблокированы, даже если служба остановлена. Для выбора другой стратегии удалите автозапуск, выполните проверку и установите новый вариант. Обновление UI или пользовательских списков рядом с EXE не переписывает уже установленную копию службы; для переноса этих изменений переустановите автозапуск.

Существующая служба `zapret`, созданная Flowseal, и другие процессы winws не перехватываются. Если они мешают установке, остановите и удалите прежний автозапуск через ту программу, в которой его создавали. Общие службы WinDivert приложение не удаляет.

## Как работает автоподбор

1. **Определяет сеть.** Источники используются последовательно: `ipwho.is`, при неудаче — `ipapi.co`, затем резервный API `2ip.me`. Показываются оператор внешнего IP и ASN. Город приблизительный и может отсутствовать.
2. **Проверяет условия.** Нужны права администратора, доступный комплект и отсутствие чужого `winws` / `winws2`. Если сеть определить не удалось, автоматическое применение недоступно, но остаётся ручная проверка.
3. **Измеряет исходное подключение.** Движок, запущенный через приложение, временно останавливается. Проверки без него дают исходный результат — baseline.
4. **Проверяет 28 кандидатов.** Каждый запускается по очереди. После пяти секунд на запуск движка выполняется один Standard-проход: 36 HTTP/TLS-проверок и отдельно 17 ping-результатов. Во время переключений возможны кратковременные обрывы соединений.
5. **Сравнивает результаты.** Как в Flowseal Standard, сначала учитывается количество успешных HTTP/TLS-проверок, при равенстве — число успешных ping. Задержка не определяет победителя. Неполные и аварийные прогоны исключаются из автоматического выбора.
6. **Перепроверяет кандидата.** Для автоматического применения требуется улучшение относительно исходного подключения и успешность всех проверяемых HTTP/TLS-соединений. Приложение повторно определяет сеть и выполняет ещё один полный Standard-проход выбранной стратегии. При смене сети или неудаче кандидат не применяется. Неподдерживаемые возможности curl показываются отдельно; они не становятся успешными проверками.
7. **Сохраняет результат.** Подтверждённая стратегия остаётся запущенной. При неудаче приложение пытается восстановить стратегию, работавшую через него до проверки. Результаты доступны в JSON-отчёте.

Если все проверяемые адреса отвечают без zapret, приложение сообщает только об этом, а не о ненужности обхода: Standard не проверяет видео и голос. Если подходящей для автоматического применения стратегии нет, лучший по счётчикам частичный результат остаётся для анализа и ручного выбора.

Успешно завершённый или отменённый кнопкой остановки первичный подбор не повторяется при каждом запуске. При обновлении с прежних пяти HTTPS-проверок завершённость старого подбора сбрасывается: результат Standard нужно получить заново. Явная отмена пользователем сохраняется. Если завершить само приложение до окончания подбора, следующий запуск может начать его заново. Повторный подбор доступен из **Обзора**, например после смены сети. Автоподбор сам не устанавливает службу: для постоянной работы нажмите **Установить с автозапуском**. Без службы новый запуск сеансового движка выполняется кнопкой **Запустить**.

Полный перебор может занять несколько минут, особенно при тайм-аутах. Перед ним завершите важные звонки и загрузки. Кнопка остановки отменяет перебор; полученные результаты сохраняются, если проверка уже началась.

## Проверка в сети Инфолинк

В комплекте сохранено описание [Инфолинк · Щёлково](profiles/infolink-shchelkovo.json), но этот профиль не выбран по умолчанию. Провайдер и город изначально пусты; при необходимости укажите их в настройках. JSON-файл служит описанием поставки и отдельно приложением не загружается. **Наличие файла не означает, что стратегия уже проверена у этого провайдера.**

1. Запустите приложение на ПК, подключённом к Инфолинку в Щёлково. Для измерения домашней линии отключите VPN и туннели.
2. Посмотрите блок **Текущая сеть**. Оператор внешнего IP может называться иначе, чем бренд в договоре; эти сведения сами по себе не подтверждают физическую линию.
3. В **Настройках** проверьте провайдера и город. Подтвердите подключение к указанной сети только если это действительно так. Подтверждение сбрасывается при новом запуске приложения.
4. Запустите **Standard · Все штатные** в разделе **Проверка**: будут перебраны все 22 BAT-стратегии комплекта, включая штатный EXP. Шесть дополнительных вариантов можно выбрать отдельно; автоподбор из **Обзора** сравнивает все 28.
5. После выбора запустите несколько видео YouTube, проверьте перемотку и несколько минут просмотра. В Discord подключитесь к голосовому каналу и проверьте звук в обе стороны.
6. Скачайте отчёт и отдельно запишите результат проверки видео и голоса. Отметки ручной проверки в интерфейсе не включаются в JSON.

На другом провайдере приложение тоже выполняет измерения. Поля профиля необязательны: обнаруженный оператор записывается отдельно, а подпись можно заполнить вручную. При обновлении с 0.2 не подтверждённая старая подпись «Инфолинк / Щёлково» очищается; пользовательские названия сохраняются. Определение IP с другого компьютера не позволяет проверить стратегии на вашей домашней линии.

## Что проверяется

| Сервис | Автоматически | Отдельная ручная проверка |
| --- | --- | --- |
| YouTube | HEAD к www.youtube.com, youtu.be, i.ytimg.com, redirector.googlevideo.com через HTTP/1.1, TLS 1.2, TLS 1.3; ping | Видеопоток Googlevideo, воспроизведение, перемотка, QUIC |
| Discord | HEAD к discord.com, gateway.discord.gg, cdn.discordapp.com, updates.discord.com в трёх режимах; ping | Подключение WebSocket, голосовой канал, голос по UDP |
| Контрольные адреса | Google, Gstatic, Cloudflare, cdnjs — те же HEAD-проверки и ping; пять публичных DNS IP — только ICMP | ICMP-ответ публичного DNS IP не доказывает работу DNS-запросов |

Список читается из `bundle/utils/targets.txt`: 12 HTTPS-адресов и 5 ping-only адресов, включая Quad9 из пользовательского комплекта Flowseal 1.10.1. Один проход даёт **36 HTTP/TLS-результатов и отдельно 17 ping-результатов**. Три режима curl для каждого HTTPS-адреса выполняются последовательно; одновременно проверяются до восьми адресов. Повторы в ручной проверке умножают весь набор.

Как в `service.bat → Run tests → Standard → All`, curl выполняет **HEAD**, не следует редиректам и ограничивает запрос пятью секундами. Колонка HTTP означает HTTP/1.1 **поверх HTTPS**, а не незашифрованное соединение. TLS-сертификаты проверяются. HTTP 301/403/404/500 при успешном завершении curl означают «хост ответил»; код виден в деталях. Тело страницы, видео и голос этот тест не проверяет. Ping выполняет три ICMP-запроса на адрес и показывается отдельно от HTTP/TLS.

Прокси из окружения и пользовательский curl-конфиг отключены; системный VPN всё равно влияет на маршрут. Ошибка TLS-рукопожатия не маскируется как неподдерживаемая возможность только по коду curl 35 или слову `schannel`. `UNSUP` не считается успехом. Подробное соответствие эталону и отличия описаны в [docs/TESTING.md](docs/TESTING.md).

Результаты тестирования приложения и непроверенные сценарии перечислены в [VERIFICATION.md](VERIFICATION.md).

## Стратегии

Комплект закреплён на ревизии Flowseal [`865da4f`](https://github.com/Flowseal/zapret-discord-youtube/tree/865da4f4c3659523bf79bc6edf0446e7d7969614): 22 исходные стратегии и 6 дополнительных кандидатов.

| Основа | Дополнительные варианты |
| --- | --- |
| GENERAL | `split-pos` со значением 2 или 3 |
| ALT11 | `repeats` со значением 4 или 12 |
| FAKE TLS AUTO | `repeats` со значением 6 или 8 |

Варианты с идентификаторами `experiment-…` генерируются в памяти. Они не являются подтверждёнными рекомендациями Flowseal для Инфолинка. Штатный `general (EXP)` тоже помечен как экспериментальный, но входит в исходные 22 файла.

Приложение читает BAT как данные, проверяет поддерживаемые аргументы и запускает `winws.exe` напрямую. Сами BAT и `service.bat` из интерфейса не исполняются. Неизвестные параметры и некорректные пути вызывают ошибку импорта. Замена `bundle` на будущую версию Flowseal может потребовать обновления парсера.

Игровой фильтр в оболочке отключён. Отсутствующие пользовательские списки создаются со стандартными служебными значениями Flowseal; существующие сохраняются. Самостоятельный запуск `service.bat` относится к инструментам upstream и может создать службу, которой оболочка не управляет.

Путь к комплекту показывается в настройках для справки. Основная тема использует `#1B1B1E` и `#D7263D`, альтернативная — `#0F0A0A` и `#82D173`. Анимации учитывают системную настройку уменьшения движения.

Начиная с 0.3.5, используется обновлённый логотип. Значок отдельно назначается окну pywebview и ярлыкам; у процесса и ярлыков приложения единый `AppUserModelID` — `Nerd3n.Zapret`. ## Данные и приватность

Постоянные данные находятся рядом с EXE, а при запуске исходников — рядом с `main.py`:

| Путь | Содержимое |
| --- | --- |
| `data/settings.json` | Настройки и итог первичного подбора |
| `data/network.key` | Локальный секрет для сравнения отпечатка сети |
| `data/webview/` | Локальное хранилище встроенного окна, включая тему |
| `data/reports/*.json` | Версия, время, профиль, обнаруженная сеть и результаты |
| `bundle/lists/*-user.txt` | Пользовательские списки, созданные при работе |

Тема хранится в `localStorage` встроенного окна. В режиме `--browser` используется отдельное хранилище выбранного браузера. Журнал содержит последние события текущего сеанса; это не постоянный журнал всех запусков. Защищённый комплект службы хранится отдельно от пользовательских данных, в `%ProgramFiles%\ZapretByNerd3n-Service`.

Внешнего сервера управления у приложения нет. Определение сети обращается к сторонним API, а проверки — к ресурсам YouTube и Discord. Эти сервисы видят внешний IP соединения. Приложение не сохраняет полный внешний IP в состоянии, журнале или отчётах. Для сравнения сети используется HMAC-отпечаток с локальным ключом, который не передаётся API.

В отчётах остаются оператор, ASN, приблизительное местоположение при наличии и введённые пользователем подписи. Просматривайте отчёт перед публикацией. Папка `data`, ключ, отчёты и пользовательские списки исключены из Git через `.gitignore`.

## Частые вопросы

**Зачем приложению локальный сервер?** Он связывает HTML-интерфейс внутри окна с Python: принимает команды и возвращает состояние процессов, службы и проверок. Сервер слушает только `127.0.0.1` и завершается при закрытии окна. Это не внешний сайт и не дополнительная служба автозапуска. Основной расход памяти интерфейса приходится на WebView2; сетевой перебор временно добавляет процессы curl. Если установлен автозапуск zapret, окно можно закрыть: продолжит работать только служба движка, без Python-интерфейса.

**Провайдер определился неправильно.** Проверяется оператор внешнего IP: при VPN или туннеле будет виден их оператор. Город в IP-базах приблизительный. Отключите VPN для проверки домашней линии и нажмите **Определить повторно**. Профиль для отчётов можно исправить вручную.

**Почему используется не только 2ip?** Несколько источников нужны на случай недоступности и ограничений API. `2ip.me` — резервный сервис. Если все источники недоступны, автоматическое применение блокируется, но ручная проверка доступна.

**Нужны права администратора.** Завершите приложение и запустите установленный ярлык либо EXE от имени администратора. Права нужны для `winws` и WinDivert; установка файлов в папку пользователя сама по себе не требует повышения прав.

**Обнаружен другой zapret.** Остановите его штатным способом в программе или службе, где запускали, затем повторите проверку. Оболочка не завершает чужие процессы принудительно.

**Проверки успешны, а видео или голос не работают.** HTTPS-проверки не охватывают видеопоток и голосовой трафик. Проверьте нужный сценарий вручную, попробуйте другой кандидат и сохраните отчёт с описанием результата в самом сервисе.

**Все адреса доступны без zapret, но обход нужен.** Доступность страниц может отличаться от доступности видео или голоса. Автоподбор не может подтвердить улучшение на этих адресах. Выберите стратегию вручную и проверьте её в YouTube или Discord.

**Окно не открывается или порт занят.** Проверьте установку WebView2 Runtime x64. Завершите другой экземпляр или запустите `ZapretByNerd3n.exe --port 17842`. Для диагностики можно явно выбрать `--browser`. Другой порт не решает конфликт одновременно работающих движков.

**Обновление завершилось ошибкой `DeleteFile`, код 5 («Отказано в доступе»).** В разобранном случае версия 0.2.0 оставалась запущенной от имени администратора, а установщик без повышения прав не мог закрыть её через Restart Manager и заменить EXE. В 0.3.2 добавлено штатное завершение приложения перед копированием. Если подготовка обновления всё ещё сообщает о занятом файле или отказе в доступе, закройте соответствующее приложение и проверьте права на выбранную папку; повторная попытка не должна обходить эту проверку. Фактически выполненные проверки сборки перечислены в [VERIFICATION.md](VERIFICATION.md).

**Приложение уже закрыто, но обновление сообщает о занятом `WinDivert64.sys`.** Windows может оставить общий драйвер загруженным после выхода `winws`. В 0.3.3 установщик сравнивает SHA-256 и сохраняет на месте только полностью совпадающий с поставкой файл. Если драйвер отличается или его невозможно проверить, исключение не применяется; завершите использующие его приложения и при необходимости перезагрузите Windows перед повторной установкой. Установщик сам не останавливает общую службу WinDivert.

**«Не удалось прочитать конфигурацию службы», Windows 1783; откат тоже завершился ошибкой.** В прежней версии длинная команда ALT11 превышала допустимый размер ответа `QueryServiceConfigW`. Служба могла остаться зарегистрированной, но остановленной. В 0.3.4 её конфигурация читается через проверенный резервный путь. Откройте обновлённое приложение от имени администратора и используйте **Запустить службу**: сохранённая стратегия и её полная команда остаются прежними. Если проверка владения или прав доступа не проходит, запуск отменяется. Не нужно удалять общий драйвер WinDivert.

**Не найден комплект или curl.** Проверьте, что архив распакован целиком и `bundle` находится рядом с EXE. Если файл удалён защитой Windows, проверьте источник сборки и событие в журнале защиты. Для HTTP-проверок нужен штатный `curl.exe` из Windows.

**После закрытия окна движок остановился.** Это поведение сеансового запуска. Для постоянной работы выберите стратегию и нажмите **Установить с автозапуском**. Уже установленная служба продолжает работать независимо от окна.

## Разработка

Нужны Git, Python 3.10+ для Windows x64 и WebView2 Runtime. Сборка использует Python 3.13.5. Backend использует стандартную библиотеку, desktop-окно — pywebview и pythonnet. npm для запуска не нужен; GSAP находится в `web/vendor`.

```powershell
git clone https://github.com/nerd-en/zapret-by-nerd3n.git
cd zapret-by-nerd3n
python -m pip install -r requirements.txt
python main.py --no-auto-setup
```

Этот режим открывает интерфейс без стартового определения сети и перебора. Для полного поведения первого запуска выполните `python main.py` в терминале с правами администратора.

| Аргумент | Назначение |
| --- | --- |
| `--no-auto-setup` | Отключить стартовое определение сети и подбор для этого запуска |
| `--no-browser` | Режим без окна и браузера: только локальный сервер |
| `--browser` | Явно открыть интерфейс во внешнем браузере вместо окна |
| `--port 17842` | Изменить порт; по умолчанию 17841 |
| `--elevate` | Запросить повышение прав через UAC |
| `--auto` | Явно обозначить первичную настройку; она включена по умолчанию, флаг не сбрасывает сохранённый результат |
| `--remove-service` | Служебный режим деинсталлятора: удалить только принадлежащую приложению службу и завершиться |
| `--prepare-update <папка>` | Служебный режим установщика: штатно закрыть приложение из указанной папки и дождаться освобождения обновляемых файлов |

Запуск тестов:

```powershell
python -m unittest discover -s tests -v
```

Проверяются импорт стратегий, аргументы процессов, отмена, выбор кандидата, смена сети, откат, ответы ресурсов и локальный API. Там, где нужен перехват трафика, используются подставные процессы и ответы. Эти тесты не подтверждают эффективность обхода у провайдера. Проверка символических ссылок Windows может быть пропущена при нехватке прав.

## Сборка

Сборка выполняется на Windows x64. Установите [Python](https://www.python.org/downloads/windows/) и [Inno Setup](https://jrsoftware.org/isinfo.php). Команды выполняются из корня проекта.

### EXE

```powershell
python -m venv .build-env
.\.build-env\Scripts\python.exe -m pip install pyinstaller==6.22.3
.\.build-env\Scripts\python.exe -m pip install -r requirements.txt
.\.build-env\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --noupx --name ZapretByNerd3n --icon assets/app.ico --add-data "web;web" --collect-data webview --hidden-import webview.platforms.winforms --hidden-import webview.platforms.edgechromium --version-file app-version.txt main.py
Copy-Item -LiteralPath .\dist\ZapretByNerd3n.exe -Destination .\ZapretByNerd3n.exe -Force
```

Последняя команда размещает EXE рядом с `bundle` и `profiles`, откуда его берёт сборщик установщика. В EXE включаются Python и интерфейс; комплект zapret упаковывается отдельно.

### Установщик

```powershell
.\installer\build-installer.ps1 -CompilerPath 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' -OutputDir .\dist -Version 0.3.5
```

Укажите фактический путь к `ISCC.exe`. Проверенная версия — Inno Setup 6.7.3. Результат: `dist\Zapret-by-nerd3n-Setup.exe` и файл SHA-256. Если политика PowerShell блокирует скрипт, выполните его в отдельном процессе без изменения постоянной политики:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\build-installer.ps1 -CompilerPath 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' -OutputDir .\dist -Version 0.3.5
```

Упаковка ZIP, контрольные суммы и публикация описаны в [docs/RELEASING.md](docs/RELEASING.md). Сценарий установщика — [installer/ZapretByNerd3n.iss](installer/ZapretByNerd3n.iss). Сборка не устанавливает приложение и не запускает драйвер.
