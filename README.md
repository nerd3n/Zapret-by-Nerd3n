# zapret by nerd3n

Приложение для Windows с графическим интерфейсом, автоматическим определением провайдера и подбором стратегий [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) для YouTube и Discord.

Движок zapret, стратегии и профиль **Инфолинк · Щёлково** уже входят в комплект. Указывать путь к zapret или скачивать его отдельно не нужно. Интерфейс открывается в браузере на этом компьютере, управление движком выполняет локальное приложение.

[Скачать из Releases](https://github.com/nerd-en/zapret-by-nerd3n/releases) · [Сообщить об ошибке](https://github.com/nerd-en/zapret-by-nerd3n/issues) · [Как выпустить релиз](docs/RELEASING.md)

**Версия 0.2.0 — предварительная.** Логика приложения и сборка проверены; эффективность стратегий на реальной линии Инфолинка пока не подтверждена. Автоподбор сравнивает HTTPS-доступность ресурсов. Воспроизведение видео и голосовой чат необходимо проверить отдельно.

## Возможности

- Запуск и остановка выбранной стратегии через интерфейс.
- Определение оператора внешнего IP, ASN и приблизительного города при наличии данных.
- Автоматическое сравнение исходного подключения и всех 28 кандидатов при первом запуске.
- Повторная проверка выбранной стратегии перед автоматическим применением.
- Ручной выбор кандидатов и от одного до трёх повторов на каждый проверяемый адрес.
- Отмена проверки, таблица результатов, сохранение и скачивание JSON-отчётов.
- Обнаружение другой запущенной копии `winws`, чтобы не смешивать результаты.
- Две темы: графит с красным акцентом и тёмная с зелёным. Выбор сохраняется в браузере.

Приложение управляет только запущенным им процессом `winws`. Оно не создаёт службу Windows, не добавляет себя в автозагрузку, не меняет hosts и системные настройки DNS.

## Установка и запуск

### Установщик

1. Откройте [Releases](https://github.com/nerd-en/zapret-by-nerd3n/releases) и выберите версию. Если релиз ещё не опубликован, используйте сборку из исходников ниже.
2. В разделе **Assets** скачайте `Zapret-by-nerd3n-Setup.exe` и запустите его.
3. Выберите папку. По умолчанию используется `%LOCALAPPDATA%\ZapretByNerd3n`.
4. В конце установки оставьте включённым запуск приложения и подтвердите запрос Windows на повышение прав.
5. Откроется интерфейс; при первом запуске начнётся определение сети и подбор стратегии.

Установщик создаёт ярлык в меню «Пуск». Ярлык на рабочем столе предлагается отдельно. Для последующих запусков используйте установленный ярлык: он запрашивает необходимые права. Отмена запроса UAC не отменяет уже завершённую установку.

### Переносная версия

1. Скачайте `zapret-by-nerd3n-portable.zip` из **Assets**.
2. Распакуйте весь архив в папку, доступную для записи, например `C:\Tools\ZapretByNerd3n`.
3. Запустите `ZapretByNerd3n.exe` через **Запуск от имени администратора**.

Перемещайте всю папку целиком: рядом с EXE должны оставаться `bundle`, `profiles` и лицензии. Путь к комплекту вычисляется относительно приложения, а не текущей рабочей папки. Архив **Source code**, который создаёт GitHub, предназначен для разработки и не содержит собранного EXE оболочки.

### Адрес и завершение работы

Обычный адрес интерфейса — `http://127.0.0.1:17841`. Сервер слушает только локальный интерфейс компьютера; открывать порт на роутере не требуется.

Чтобы остановить движок и сервер, нажмите **Завершить приложение** внизу интерфейса. **Закрытие вкладки браузера не завершает программу.** При аварийном завершении оболочки её дочерний `winws` останавливается через Windows Job Object.

### Обновление и удаление

Перед обновлением или удалением завершите приложение через интерфейс. Новый установщик можно запустить для той же папки. Пользовательские списки, настройки, отчёты и выбранные `ACTIVE_*.bin` сохраняются; штатные файлы комплекта обновляются.

Удаление доступно через параметры Windows и ярлык в меню «Пуск». Созданные во время работы данные могут остаться в папке приложения. Если они больше не нужны, после удаления программы удалите оставшуюся папку вручную. Для переносной версии достаточно завершить приложение и удалить её папку.

## Как работает автоподбор

1. **Определяет сеть.** Источники используются последовательно: `ipwho.is`, при неудаче — `ipapi.co`, затем резервный API `2ip.me`. Показываются оператор внешнего IP и ASN. Город приблизительный и может отсутствовать.
2. **Проверяет условия.** Нужны права администратора, доступный комплект и отсутствие чужого `winws` / `winws2`. Если сеть определить не удалось, автоматическое применение недоступно, но остаётся ручная проверка.
3. **Измеряет исходное подключение.** Движок, запущенный через приложение, временно останавливается. Проверки без него дают исходный результат — baseline.
4. **Проверяет 28 кандидатов.** Каждый запускается по очереди. Выполняются два запроса к каждому из пяти ресурсов: 10 проверок на кандидата. Во время переключений возможны кратковременные обрывы соединений.
5. **Сравнивает результаты.** Сначала учитывается успешность худшего из двух сервисов, затем общая доля успеха и медианное время успешных запросов. При равных результатах предпочтение отдаётся штатной стратегии. Неполные и аварийные прогоны исключаются из автоматического выбора.
6. **Перепроверяет кандидата.** Для автоматического применения нужны все 10 успешных проверок и улучшение относительно исходного подключения. Приложение повторно определяет сеть и выполняет ещё один полный прогон выбранной стратегии. При смене сети или неудаче кандидат не применяется.
7. **Сохраняет результат.** Подтверждённая стратегия остаётся запущенной. При неудаче приложение пытается восстановить стратегию, работавшую через него до проверки. Результаты доступны в JSON-отчёте.

Если все адреса доступны без zapret, приложение не объявляет победителя по одной лишь скорости. Если полностью успешной стратегии нет, частичные результаты остаются для анализа и ручного выбора.

Успешно завершённый или отменённый кнопкой остановки первичный подбор не повторяется при каждом запуске. Если завершить само приложение до окончания подбора, следующий запуск может начать его заново. Повторный подбор также доступен из **Обзора**, например после смены сети. Выбор сохраняется в настройках, но автоматический запуск сохранённой стратегии при следующем открытии и при входе в Windows в этой версии не реализован — используйте кнопку **Запустить**.

Полный перебор может занять несколько минут, особенно при тайм-аутах. Перед ним завершите важные звонки и загрузки. Кнопка остановки отменяет перебор; полученные результаты сохраняются, если проверка уже началась.

## Проверка в сети Инфолинк

В комплект входит описание профиля [Инфолинк · Щёлково](profiles/infolink-shchelkovo.json). Такие же значения предустановлены в настройках приложения; подпись сети в отчётах меняется через настройки. JSON-файл служит описанием поставки и отдельно приложением не загружается. **Наличие профиля не означает, что стратегия уже проверена у этого провайдера.**

1. Запустите приложение на ПК, подключённом к Инфолинку в Щёлково. Для измерения домашней линии отключите VPN и туннели.
2. Посмотрите блок **Текущая сеть**. Оператор внешнего IP может называться иначе, чем бренд в договоре; эти сведения сами по себе не подтверждают физическую линию.
3. В **Настройках** проверьте провайдера и город. Подтвердите подключение к указанной сети только если это действительно так. Подтверждение сбрасывается при новом запуске приложения.
4. Запустите автоподбор или выберите кандидатов в разделе **Проверка**.
5. После выбора запустите несколько видео YouTube, проверьте перемотку и несколько минут просмотра. В Discord подключитесь к голосовому каналу и проверьте звук в обе стороны.
6. Скачайте отчёт и отдельно запишите результат проверки видео и голоса. Отметки ручной проверки в интерфейсе не включаются в JSON.

На другом провайдере приложение тоже выполняет измерения. Укажите его название и город в настройках, чтобы отчёт не был ошибочно подписан как проверка Инфолинка. Определение IP с другого компьютера не позволяет проверить стратегии на вашей домашней линии.

## Что проверяется

| Сервис | Автоматически | Отдельная ручная проверка |
| --- | --- | --- |
| YouTube | Главная страница, тестовое изображение, метаданные oEmbed | Видеопоток Googlevideo, воспроизведение, перемотка, QUIC |
| Discord | Главная страница и REST Gateway API | Подключение WebSocket, голосовой канал, голос по UDP |

Системный `curl.exe` выполняет HTTPS-запросы по TCP/HTTP 1.1 с проверкой TLS-сертификата, кода ответа и ожидаемого содержимого. HTTP 403/404, заглушки и ошибки соединения не считаются успехом. Используется системное разрешение DNS. Прокси из переменных окружения и настроек curl отключены для этих запросов; VPN на уровне системы всё равно влияет на маршрут.

Тайм-аут запроса — 8 секунд, подключения — 3 секунды. Размер ответа ограничен 2 МиБ; одновременно выполняются не более четырёх запросов. Это проверка доступности, а не измерение скорости загрузки видео.

Результаты тестирования приложения и непроверенные сценарии перечислены в [VERIFICATION.md](VERIFICATION.md).

## Стратегии

Комплект закреплён на ревизии Flowseal [`865da4f`](https://github.com/Flowseal/zapret-discord-youtube/tree/865da4f4c3659523bf79bc6edf0446e7d7969614): 22 исходные стратегии и 6 дополнительных кандидатов.

| Основа | Дополнительные варианты |
| --- | --- |
| GENERAL | `split-pos` со значением 2 или 3 |
| ALT11 | `repeats` со значением 4 или 12 |
| FAKE TLS AUTO | `repeats` со значением 6 или 8 |

Варианты с идентификаторами `experiment-…` генерируются в памяти. Они не являются подтверждёнными рекомендациями Flowseal для Инфолинка. Штатный `general (EXP)` тоже помечен как экспериментальный, но входит в исходные 22 файла.

Приложение читает BAT как данные, проверяет поддерживаемые аргументы и запускает `winws.exe` напрямую. Сами BAT и `service.bat` из интерфейса не исполняются. Неизвестные параметры и некорректные пути вызывают ошибку импорта. Замена `bundle` на будущую версию Flowseal может потребовать обновления парсера.

Игровой фильтр в оболочке отключён. Отсутствующие пользовательские списки создаются со стандартными служебными значениями Flowseal; существующие сохраняются. Самостоятельный запуск `service.bat` относится к инструментам upstream и может создать службу, которой оболочка не управляет.

## Интерфейс

| Раздел | Назначение |
| --- | --- |
| Обзор | Автоподбор, обнаруженная сеть, выбор и запуск стратегии |
| Стратегии | Поиск, описание кандидата, источник и аргументы `winws` |
| Проверка | Кандидаты, повторы, исходный замер, отмена, результаты и отчёты |
| Журнал | События текущего сеанса и фильтр ошибок |

Путь к комплекту показывается в настройках для справки. Основная тема использует `#1B1B1E` и `#D7263D`, альтернативная — `#0F0A0A` и `#82D173`. Анимации учитывают системную настройку уменьшения движения.

## Данные и приватность

Постоянные данные находятся рядом с EXE, а при запуске исходников — рядом с `main.py`:

| Путь | Содержимое |
| --- | --- |
| `data/settings.json` | Настройки и итог первичного подбора |
| `data/network.key` | Локальный секрет для сравнения отпечатка сети |
| `data/reports/*.json` | Версия, время, профиль, обнаруженная сеть и результаты |
| `bundle/lists/*-user.txt` | Пользовательские списки, созданные при работе |

Тема хранится в `localStorage` браузера. Журнал содержит последние события текущего сеанса; это не постоянный журнал всех запусков.

Внешнего сервера управления у приложения нет. Определение сети обращается к сторонним API, а проверки — к ресурсам YouTube и Discord. Эти сервисы видят внешний IP соединения. Приложение не сохраняет полный внешний IP в состоянии, журнале или отчётах. Для сравнения сети используется HMAC-отпечаток с локальным ключом, который не передаётся API.

В отчётах остаются оператор, ASN, приблизительное местоположение при наличии и введённые пользователем подписи. Просматривайте отчёт перед публикацией. Папка `data`, ключ, отчёты и пользовательские списки исключены из Git через `.gitignore`.

## Частые вопросы

**Провайдер определился неправильно.** Проверяется оператор внешнего IP: при VPN или туннеле будет виден их оператор. Город в IP-базах приблизительный. Отключите VPN для проверки домашней линии и нажмите **Определить повторно**. Профиль для отчётов можно исправить вручную.

**Почему используется не только 2ip?** Несколько источников нужны на случай недоступности и ограничений API. `2ip.me` — резервный сервис. Если все источники недоступны, автоматическое применение блокируется, но ручная проверка доступна.

**Нужны права администратора.** Завершите приложение и запустите установленный ярлык либо EXE от имени администратора. Права нужны для `winws` и WinDivert; установка файлов в папку пользователя сама по себе не требует повышения прав.

**Обнаружен другой zapret.** Остановите его штатным способом в программе или службе, где запускали, затем повторите проверку. Оболочка не завершает чужие процессы принудительно.

**Проверки успешны, а видео или голос не работают.** HTTPS-проверки не охватывают видеопоток и голосовой трафик. Проверьте нужный сценарий вручную, попробуйте другой кандидат и сохраните отчёт с описанием результата в самом сервисе.

**Все адреса доступны без zapret, но обход нужен.** Доступность страниц может отличаться от доступности видео или голоса. Автоподбор не может подтвердить улучшение на этих адресах. Выберите стратегию вручную и проверьте её в YouTube или Discord.

**Интерфейс не открывается или порт занят.** Убедитесь, что приложение работает, и откройте `http://127.0.0.1:17841`. Завершите другой экземпляр или запустите `ZapretByNerd3n.exe --port 17842`. Другой порт интерфейса не решает конфликт одновременно работающих движков.

**Не найден комплект или curl.** Проверьте, что архив распакован целиком и `bundle` находится рядом с EXE. Если файл удалён защитой Windows, проверьте источник сборки и событие в журнале защиты. Для HTTP-проверок нужен штатный `curl.exe` из Windows.

**После повторного открытия движок остановлен.** Завершение приложения останавливает его движок. Автозапуск сохранённого варианта при новом открытии в этой версии не реализован. Выберите стратегию в **Обзоре** и нажмите **Запустить**.

## Разработка

Нужны Git и Python 3.10+ для Windows x64. Готовая сборка 0.2.0 проверялась с Python 3.13.5. Backend использует стандартную библиотеку; npm для запуска не нужен. GSAP уже находится в `web/vendor`.

```powershell
git clone https://github.com/nerd-en/zapret-by-nerd3n.git
cd zapret-by-nerd3n
python main.py --no-auto-setup
```

Этот режим открывает интерфейс без стартового определения сети и перебора. Для полного поведения первого запуска выполните `python main.py` в терминале с правами администратора.

| Аргумент | Назначение |
| --- | --- |
| `--no-auto-setup` | Отключить стартовое определение сети и подбор для этого запуска |
| `--no-browser` | Запустить сервер без открытия вкладки |
| `--port 17842` | Изменить порт; по умолчанию 17841 |
| `--elevate` | Запросить повышение прав через UAC |
| `--auto` | Явно обозначить первичную настройку; она включена по умолчанию, флаг не сбрасывает сохранённый результат |

Запуск тестов:

```powershell
python -m unittest discover -s tests -v
```

Проверяются импорт стратегий, аргументы процессов, отмена, выбор кандидата, смена сети, откат, ответы ресурсов и локальный API. Там, где нужен перехват трафика, используются подставные процессы и ответы. Эти тесты не подтверждают эффективность обхода у провайдера. Проверка символических ссылок Windows может быть пропущена при нехватке прав.

## Сборка

Сборка выполняется на Windows x64. Установите [Python](https://www.python.org/downloads/windows/) и [Inno Setup](https://jrsoftware.org/isinfo.php). Команды выполняются из корня проекта.

### EXE

```powershell
python -m venv .build-env
.\.build-env\Scripts\python.exe -m pip install pyinstaller==6.22.3
.\.build-env\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --name ZapretByNerd3n --add-data "web;web" --version-file app-version.txt main.py
Copy-Item -LiteralPath .\dist\ZapretByNerd3n.exe -Destination .\ZapretByNerd3n.exe -Force
```

Последняя команда размещает EXE рядом с `bundle` и `profiles`, откуда его берёт сборщик установщика. В EXE включаются Python и интерфейс; комплект zapret упаковывается отдельно.

### Установщик

```powershell
.\installer\build-installer.ps1 -CompilerPath 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' -OutputDir .\dist -Version 0.2.0
```

Укажите фактический путь к `ISCC.exe`. Проверенная версия — Inno Setup 6.7.3. Результат: `dist\Zapret-by-nerd3n-Setup.exe` и файл SHA-256. Если политика PowerShell блокирует скрипт, выполните его в отдельном процессе без изменения постоянной политики:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\build-installer.ps1 -CompilerPath 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' -OutputDir .\dist -Version 0.2.0
```

Упаковка ZIP, контрольные суммы и публикация описаны в [docs/RELEASING.md](docs/RELEASING.md). Сценарий установщика — [installer/ZapretByNerd3n.iss](installer/ZapretByNerd3n.iss). Сборка не устанавливает приложение и не запускает драйвер.
