# zapret by nerd3n 0.3.0

Предварительный выпуск для Windows 10/11 x64.

## Изменения

- Отдельное окно Python-приложения на pywebview / WebView2 с прежним интерфейсом и двумя темами. Вкладка внешнего браузера для обычного запуска больше не нужна.
- Провайдер и город по умолчанию пусты. Обнаруженный оператор показывается отдельно; неподтверждённая старая подпись Инфолинка очищается при обновлении.
- Установка выбранной стратегии как службы Windows с автозапуском. Служба работает после закрытия окна и запускается при старте системы.
- Отдельные команды запуска, остановки и удаления службы. Обычный сеансовый запуск сохранён.
- Защищённая копия комплекта службы в Program Files, проверка происхождения бинарников и владения службой. Чужие процессы и службы не удаляются.
- Закрытие окна завершает сеансовый движок и сервер. Деинсталлятор сначала удаляет нашу службу с запросом UAC; при отказе UAC или если служба осталась зарегистрирована, прекращает удаление приложения.
- Проверка работающих процессов через Windows API без периодического запуска PowerShell.

Автоподбор сохранён: 22 штатные стратегии, 6 дополнительных кандидатов, исходный замер, повторная проверка победителя и JSON-отчёты. Установка автозапуска выполняется только отдельной кнопкой пользователя.

## Установка

Скачайте `Zapret-by-nerd3n-Setup.exe` либо распакуйте весь `zapret-by-nerd3n-portable.zip`. Python для готового EXE не требуется. Для окна нужен Microsoft Edge WebView2 Runtime x64; для движка и службы — права администратора.

Контрольные суммы: `SHA256SUMS.txt`. Исходники: `zapret-by-nerd3n-source.zip`.

## Ограничения

Работа обхода на реальной линии Инфолинка ещё не подтверждена. HTTPS-проверки не заменяют проверку видео YouTube и голоса Discord. Реальная установка службы, её запуск после перезагрузки и удаление через установщик требуют отдельной проверки на целевом ПК; текущая среда уже использует сторонний winws.

Для нового подбора при установленной службе сначала удалите автозапуск. Остановка службы оставляет автоматический запуск при следующем старте Windows.

EXE и установщик не подписаны сертификатом издателя. Лицензия оболочки — MIT; лицензии компонентов сохранены в поставке.
