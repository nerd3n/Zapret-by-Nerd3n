# zapret by nerd3n 0.3.2

Предварительный выпуск для Windows 10/11 x64. Исправление обновления установленной программы.

В журнале неудачной установки обнаружена причина: `ZapretByNerd3n.exe` версии 0.2.0 продолжал работать с повышенными правами. Установщик запускался с обычными правами, Restart Manager получал отказ в доступе, а замена EXE завершалась ошибкой `DeleteFile`, код 5.

В 0.3.2 перед копированием файлов выполняется отдельная подготовка обновления:

- Установщик запускает вспомогательный режим нового EXE из временной папки. Он проверяет, что найденная запущенная копия относится к выбранной папке установки, и запрашивает её штатное завершение через локальный `/api/exit`.
- Поддерживается совместимый API версии 0.2.0, включая запуск приложения на нестандартном локальном порту. Для завершения приложения отдельное повышение прав не запрашивается.
- Установщик ждёт освобождения EXE и обновляемых файлов движка до 60 секунд. Если файл занят или доступ запрещён, установка останавливается до замены файлов и сообщает причину.
- Закрытие приложения останавливает его собственный сеансовый `winws`. Чужие `winws`, другие копии приложения из иных папок и службы не завершаются принудительно. Установленная служба `ZapretByNerd3n` продолжает использовать свой защищённый комплект в Program Files.
- Настройки, отчёты, пользовательские списки и выбранные `ACTIVE_*.bin` сохраняются. Штатный комплект обновляется обычным порядком после успешной подготовки.

Для обновления скачайте новый `Zapret-by-nerd3n-Setup.exe` и выберите существующую папку. Если подготовка сообщает об оставшейся блокировке, завершите соответствующее приложение штатно и повторите установку. Контрольные суммы готовых артефактов публикуются в `SHA256SUMS.txt`.

Отдельное окно, Flowseal Standard (36 HTTP/TLS и отдельно 17 ping-результатов), автоподбор и управление собственной службой сохраняются. Standard подтверждает только ответы проверяемых адресов: видео YouTube, QUIC, WebSocket и голос Discord требуют отдельной проверки. Эффективность на линии Инфолинка не подтверждена.

Обновление работающей копии 0.2.0 в отдельном тестовом каталоге прошло успешно: новый EXE запустился как 0.3.2, настройки, отчёты, пользовательский список и оба выбранных payload-файла сохранились. При искусственно удерживаемом EXE установка остановилась до копирования; хеши всех файлов остались прежними. Запущенная пользовательская копия из другой папки продолжила работать. Поиск реальной повышенной копии 0.2.0 проверен без её остановки; само обновление поверх повышенного процесса на целевой установке ещё не выполнялось. Подробности — в [VERIFICATION.md](../VERIFICATION.md). Работа службы после перезагрузки требует отдельной проверки.

EXE и установщик не подписаны сертификатом издателя. Python для готовой программы не требуется; для окна нужен Microsoft Edge WebView2 Runtime x64. Лицензия оболочки — MIT, лицензии сторонних компонентов сохранены в поставке.
