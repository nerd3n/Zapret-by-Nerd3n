# zapret by nerd3n 0.3.8

Предварительный выпуск для Windows 10/11 x64. Проект перенесён в
[nerd3n/Zapret-by-Nerd3n](https://github.com/nerd3n/Zapret-by-Nerd3n);
локальная папка проекта теперь называется `Zapret by Nerd3n`. Ссылки на скачивание,
ошибки, исходники и инструкции выпуска ведут в новый репозиторий.

Обновлён служебный список IPSet `bundle/.service/ipset-service.txt` из
[коммита Flowseal `249a704`](https://github.com/Flowseal/zapret-discord-youtube/commit/249a70424aae2676f99c5363e21073ed89873eda)
от 26 сентября 2026 года: 33 048 строк вместо 32 126. Ревизия комплекта закреплена
на [`eb16c1419057e36b8a36fbe7c959483450e6ac8b`](https://github.com/Flowseal/zapret-discord-youtube/tree/eb16c1419057e36b8a36fbe7c959483450e6ac8b).
Последний релиз upstream остаётся [1.10.3](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.3):
движок, драйвер, 22 штатные BAT-стратегии и остальные списки не изменились.
Рабочий `lists/ipset-all.txt` сохраняет прежний выключенный режим; обновление
служебного списка само по себе не включает фильтр IPSet. Пользовательские списки,
выбранные `ACTIVE_*.bin` и дополнительная ping-цель Quad9 сохраняются.

Сохранена диагностика немедленного завершения сеансового `winws`, добавленная
в 0.3.7. Сообщение включает код выхода и последний фрагмент вывода именно этого
процесса. Сведения записываются в `data/last-startup-failure.json` рядом с EXE
и остаются после закрытия окна. Если сбой повторится, сохраните полный текст
ошибки и этот файл, предварительно просмотрев локальные пути и вывод.
**Причина сообщённого кода 2 пока не установлена; исправление этой причины
в данном выпуске не заявляется.**

Для первого запуска достаточно `ZapretByNerd3n.exe`: положите его в отдельную
папку с правом записи, и он извлечёт встроенный комплект и лицензии рядом с собой.
Существующие файлы не перезаписываются. Замена только EXE обновляет оболочку;
для обновления штатных файлов `bundle` с сохранением пользовательских данных
используйте `Zapret-by-nerd3n-Setup.exe` и прежнюю папку установки.
Portable ZIP, архив исходников и контрольные суммы остаются вариантами поставки.
Python для готового EXE не требуется; для окна нужен WebView2 Runtime x64,
для запуска движка — права администратора.

Сохранены исправления чтения длинной команды службы из 0.3.4 и обновления
идентичного драйвера WinDivert из 0.3.3. Установщик запрашивает штатное завершение
выбранной копии через `/api/exit`, сохраняет пользовательские данные и не
останавливает чужие процессы `winws` или общую службу WinDivert.

Фактически выполненные проверки готовой версии и их ограничения указаны в
[VERIFICATION.md](../VERIFICATION.md). Эффективность стратегий на линии Инфолинка
и автозапуск службы после перезагрузки пока не подтверждены. Автоматические
HEAD/ping-проверки не подтверждают воспроизведение YouTube, QUIC, WebSocket
или голос Discord. EXE и установщик не подписаны сертификатом издателя;
контрольные суммы опубликованы в `SHA256SUMS.txt`.
