# zapret by nerd3n 0.2.0

Предварительный выпуск приложения для Windows 10/11 x64. В комплект входят движок Flowseal zapret, 22 штатные стратегии, 6 дополнительных кандидатов и профиль «Инфолинк · Щёлково».

## Возможности

- Локальный интерфейс на русском: запуск, остановка, проверка стратегий и журнал.
- Определение провайдера по внешнему IP с резервными источниками, включая 2ip.me.
- Первоначальный автоподбор: исходный замер, сравнение кандидатов, повторная проверка и применение подтверждённого результата.
- Отмена проверки, ручной выбор кандидатов и JSON-отчёты.
- Две темы оформления. Путь к встроенному комплекту определяется автоматически.

## Что скачать

- `Zapret-by-nerd3n-Setup.exe` — обычная установка с ярлыком и удалением через Windows.
- `zapret-by-nerd3n-portable.zip` — переносная версия. Распакуйте весь архив и запустите EXE от имени администратора.
- `zapret-by-nerd3n-source.zip` — исходники, документация и закреплённый комплект Flowseal.
- `SHA256SUMS.txt` — контрольные суммы файлов выпуска.

Python для готовой программы не требуется. Для запуска winws нужны права администратора. После установки подтвердите запрос UAC и дождитесь подбора. Для выхода используйте «Завершить приложение»: закрытие вкладки не останавливает движок.

## Проверки и ограничения

71 автоматический тест прошёл; 1 тест пропущен из-за отсутствия права создания символических ссылок Windows. Проверены интерфейс, запуск готового EXE и компиляция установщика. Реальная установка и удаление на отдельном ПК пока не проверялись.

Эффективность стратегий на реальной линии Инфолинка ещё не подтверждена. Автоподбор проверяет HTTPS-доступность; видео YouTube, QUIC, WebSocket и голос Discord требуют отдельной проверки. Полностью успешный исходный замер не считается доказательством работы обхода.

Автозапуск при входе в Windows и автоматическое восстановление процесса при повторном открытии приложения в этой версии отсутствуют. Результат подбора сохраняется; для следующего запуска стратегии используйте кнопку «Запустить».
