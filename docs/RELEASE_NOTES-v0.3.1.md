# zapret by nerd3n 0.3.1

Предварительный выпуск для Windows 10/11 x64.

Исправлена недостаточная проверка подключения: прежние пять HTTPS-запросов заменены на Flowseal Standard из предоставленного комплекта 1.10.1.

- 36 проверок HTTP/1.1, TLS 1.2 и TLS 1.3 плюс отдельно 17 ping-результатов за проход.
- Прямые проверки Googlevideo redirector, Discord Gateway, CDN и Updates; контрольные адреса Google, Cloudflare и пять публичных DNS IP.
- Кнопка **Standard · Все штатные** перебирает все 22 BAT-стратегии комплекта; шесть дополнительных вариантов можно выбрать отдельно.
- HTTP/TLS и ping показаны раздельно. Подробности содержат адрес, режим, статус, HTTP-код и ошибку. UNSUP не считается успехом.
- Лучший кандидат определяется по числу HTTP/TLS OK, затем успешных ping. Неполные результаты, дубли и сбой движка исключаются из автоприменения.
- Старые 5/5 не используются как результат Standard. Успешный baseline больше не означает «обход не нужен».
- При обновлении с прежнего теста требуется новый Standard-подбор. Явная отмена автоподбора сохраняется.

Сохранены отдельное Python-окно, комплект движка, пустой профиль по умолчанию и управление службой с автозапуском Windows.

Скачайте `Zapret-by-nerd3n-Setup.exe` либо распакуйте весь `zapret-by-nerd3n-portable.zip`. Python для готового EXE не требуется. Для окна нужен Microsoft Edge WebView2 Runtime x64. Контрольные суммы: `SHA256SUMS.txt`.

Standard проверяет доступность хостов. Ответ HTTP 403/404 при успешном завершении curl считается полученным ответом, как в Flowseal, и не доказывает работу содержимого. Видео YouTube, QUIC и голос Discord требуют проверки в приложениях. Эффективность на линии Инфолинка и реальное управление службой после перезагрузки пока не подтверждены.

Подробности теста — в `docs/TESTING.md`, результаты проверки сборки — в `VERIFICATION.md`. EXE и установщик не подписаны сертификатом издателя.
