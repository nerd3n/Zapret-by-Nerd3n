# zapret by nerd3n 0.3.6

Предварительный выпуск для Windows 10/11 x64. Для первого запуска теперь достаточно скачать один **`ZapretByNerd3n.exe`** и положить его в отдельную папку с правом записи.

- В EXE встроены движок zapret, DLL, драйвер, стратегии, списки, утилиты, справочные профили и лицензии. Искать путь к другой установленной копии или скачивать движок отдельно не нужно.
- При обычном запуске отсутствующие файлы извлекаются в `bundle`, `profiles` и `licenses` рядом с EXE. Для этого интернет не требуется; определение сети и проверки подключения используют интернет.
- Существующие файлы не перезаписываются, включая пользовательские списки и выбранные `ACTIVE_*.bin`. Настройки и отчёты остаются в `data`.
- Служебные режимы обновления и удаления службы выполняются до извлечения комплекта. Запуск из исходников по-прежнему использует `bundle` репозитория.
- В релиз добавлен отдельный EXE. Установщик, portable ZIP с разложенными файлами и документацией, архив исходников и контрольные суммы остаются доступными вариантами поставки.

Один EXE означает один файл для скачивания: после запуска рядом с ним появляются рабочие файлы. Не удаляйте `bundle` во время работы; переносите всю папку вместе с `data`, если хотите сохранить свои настройки. Установленная служба использует отдельную защищённую копию в Program Files и продолжает работать после закрытия окна.

Для обновления отдельного EXE завершите приложение и замените файл. Существующий `bundle` при этом сохраняется; для обновления штатного движка и списков используйте установщик в той же папке. Пользовательские данные сохраняются. Первый запуск и автоподбор сами не устанавливают службу: для автозапуска Windows есть отдельная команда в интерфейсе.

Python для готовой программы не нужен. Для окна требуется Microsoft Edge WebView2 Runtime x64; для запуска движка и проверки стратегий нужны права администратора. Сохраняются значки и AppUserModelID из 0.3.5, исправления чтения длинной команды службы и проверки устойчивого запуска из 0.3.4, а также подготовка обновления с сохранением идентичного драйвера из 0.3.3.

Проверен запуск из пустой папки, содержащей только EXE: извлечены 62 файла, доступны все 28 стратегий. Повторный запуск сохранил тестовые пользовательские файлы и восстановил отсутствующую стратегию. Из 298 Python-тестов прошли 294, четыре пропущены из-за ограничения Windows на символические ссылки. Подробные результаты — в [VERIFICATION.md](../VERIFICATION.md). Flowseal Standard проверяет HTTP/TLS и ping; видео YouTube, QUIC, WebSocket и голос Discord требуют отдельной проверки. Эффективность на линии Инфолинка и автозапуск службы после перезагрузки здесь не подтверждаются.

EXE и установщик не подписаны сертификатом издателя. Контрольные суммы файлов — в `SHA256SUMS.txt`; исходники — в `zapret-by-nerd3n-source.zip`. Лицензия оболочки — MIT, условия сторонних компонентов сохранены в поставке.
