# zapret by nerd3n 0.3.5

Предварительный выпуск для Windows 10/11 x64. Обновлён логотип и настройка значков приложения.

- Новое изображение используется в интерфейсе, favicon, EXE и установщике.
- Окно pywebview получает ICO-иконку явно. Процесс и ярлыки приложения используют единый `AppUserModelID` — `Nerd3n.Zapret`.
- В ярлыках установщика явно задан значок `ZapretByNerd3n.exe` с индексом 0.
- Кадры ICO используют формат DIB с прозрачностью для совместимости с WinForms.

Эти изменения относятся к значкам ярлыков и работающего окна. Закрепление на панели задач пользователь выполняет через Windows самостоятельно.

Сохраняются исправления 0.3.4: чтение длинной конфигурации службы с проверкой владения и ACL, полная команда `ImagePath` и трёхсекундная проверка устойчивого запуска. Настройки и пользовательские данные сохраняются при обновлении.

Из 258 Python-тестов прошли 256, два пропущены из-за ограничения Windows на символические ссылки. Проверены обновление 0.3.4 → 0.3.5 с сохранением 12 пользовательских файлов, запуск готового EXE, встроенный значок и параметры ярлыков Windows. Подробные результаты — в [VERIFICATION.md](../VERIFICATION.md). Эффективность на линии Инфолинка и автозапуск службы после перезагрузки требуют отдельной проверки.

Python для готовой программы не нужен; для окна требуется WebView2 Runtime x64. EXE и установщик не подписаны сертификатом издателя. Контрольные суммы — в `SHA256SUMS.txt`.
