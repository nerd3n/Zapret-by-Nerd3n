# zapret by nerd3n 0.3.4

Предварительный выпуск для Windows 10/11 x64. Исправление чтения конфигурации службы с длинной командой, проверка устойчивого запуска и новый логотип.

При установке ALT11 полная команда `ImagePath` занимала 8216 кодовых единиц UTF-16 — 16 432 байта, а ответ `QueryServiceConfigW` требовал 16 598 байт при ограничении API в 8 КБ. Windows возвращала RPC 1734/1783; служба оставалась зарегистрированной и остановленной, а откат не мог прочитать её конфигурацию. Причина подтверждена чтением SCM и реестра без изменения службы.

В 0.3.4 исправлено чтение состояния и конфигурации:

- Сохраняется прямой запуск `winws.exe` с полной командой `ImagePath` и прежними аргументами выбранной стратегии. Движок, DLL и списки службы остаются в защищённой копии в Program Files.
- Только при известных ошибках RPC 1734/1783 либо ошибке 122 с требуемым буфером больше 8 КБ приложение читает конфигурацию из реестра. Проверяются защищённый ACL, ownership marker со схемой 1 и хеш команды. Резервный путь ничего не записывает в реестр; другие ошибки SCM не разрешают обход проверки.
- Текущее состояние и PID всегда читаются через диспетчер служб Windows. Кнопка **Запустить службу** запускает проверенную собственную службу с сохранённой полной командой.
- После перехода в running приложение ещё 3 секунды проверяет, что служба не завершилась сразу после старта. Быстрый выход процесса становится ошибкой установки или запуска.
- Добавлен логотип в интерфейс, favicon, EXE и установщик. Исходный рисунок сохранён без перерисовки и обрезки; для ICO подготовлены стандартные размеры.

Если вы получили Windows 1783 и сообщение о незавершённом откате, обновите приложение до 0.3.4, откройте его от имени администратора и нажмите **Запустить службу**. При отказе проверки принадлежности или прав доступа приложение покажет ошибку. Общую службу WinDivert удалять не требуется.

Сохраняются исправления установщика: штатное закрытие своей копии через `/api/exit`, ожидание освобождения заменяемых файлов до 60 секунд и сохранение на месте только `WinDivert64.sys`, совпадающего по SHA-256 с поставкой. Настройки, отчёты, пользовательские списки и выбранные `ACTIVE_*.bin` сохраняются. Чужие процессы, службы и общий драйвер WinDivert не останавливаются и не удаляются автоматически.

На проверенном ПК ALT11 успешно запущена с исходной полной командой и автоматическим типом запуска. Выполнено обновление установленной копии 0.3.3 → 0.3.4 с сохранением 12 проверенных пользовательских файлов. Служба сохранила тот же PID при обновлении, открытии и закрытии окна. Из 251 Python-теста прошли 249, ещё 2 пропущены; все 18 JavaScript-тестов прошли. Работа после перезагрузки Windows требует отдельной проверки. Подробные результаты — в [VERIFICATION.md](../VERIFICATION.md).

Flowseal Standard по-прежнему проверяет 36 HTTP/TLS-соединений и отдельно 17 ping-результатов на проход. Видео YouTube, QUIC, WebSocket и голос Discord требуют ручной проверки; эффективность на реальной линии Инфолинка не подтверждена.

Python для готовой программы не требуется; для окна нужен Microsoft Edge WebView2 Runtime x64. EXE и установщик не подписаны сертификатом издателя. Контрольные суммы публикуются в `SHA256SUMS.txt`. Лицензия оболочки — MIT, лицензии сторонних компонентов сохранены в поставке.
