# zapret by nerd3n 0.3.3

Предварительный выпуск для Windows 10/11 x64. Исправление обновления при остающемся загруженным драйвере WinDivert.

При обновлении через 0.3.2 приложение и его сеансовый `winws` штатно завершились, но Windows продолжала удерживать `bundle/bin/WinDivert64.sys`: проверка замены возвращала ошибку совместного доступа, код 32. Общий драйвер может оставаться загруженным после выхода использовавшего его процесса. Установленный файл при этом полностью совпадал по SHA-256 с драйвером новой поставки.

В 0.3.3 установщик сохраняет такой файл на месте:

- Исключение применяется только к `bundle/bin/WinDivert64.sys` и только при совпадении SHA-256 с драйвером внутри установщика. Ожидаемая сумма вычисляется из файла пакета при компиляции.
- Вспомогательный режим не требует освобождения идентичного драйвера, а Inno пропускает его копирование. Файл не перезаписывается и не переименовывается.
- Другой, изменённый или недоступный для проверки драйвер не получает исключения. Все остальные EXE, DLL и SYS проходят обычную проверку готовности к замене.
- Общая служба WinDivert не останавливается и не удаляется. Чужие процессы и драйверы не завершаются; отсутствие `winws.exe` само по себе не означает, что WinDivert больше никто не использует.

Сохраняется подготовка обновления из 0.3.2: найденная копия приложения из выбранной папки получает штатный запрос `/api/exit`, затем установщик ждёт освобождения заменяемых файлов до 60 секунд. Поддерживается API 0.2.0 и нестандартный локальный порт. При остающейся блокировке или отказе в доступе установка останавливается до копирования. Настройки, отчёты, пользовательские списки и выбранные `ACTIVE_*.bin` сохраняются. Наша установленная служба продолжает использовать отдельный защищённый комплект в Program Files.

Для обновления запустите `Zapret-by-nerd3n-Setup.exe` и выберите существующую папку приложения. Если занятый драйвер отличается от поставки, завершите использующие его приложения и при необходимости перезагрузите Windows перед повторной установкой. Установщик не снимает такую блокировку принудительно.

Обновление пользовательской установки 0.2.0 → 0.3.3 прошло успешно при оставшемся загруженном драйвере: код завершения 0, перезагрузка не потребовалась, настройки и отчёты сохранились. Установленный EXE запущен и проверен; драйвер остался работать с прежним содержимым. Прошли 229 Python-тестов, ещё 2 пропущены из-за прав Windows на символические ссылки. Подробности и оставшиеся ограничения — в [VERIFICATION.md](../VERIFICATION.md).

Отдельное окно, Flowseal Standard (36 HTTP/TLS и отдельно 17 ping-результатов), автоподбор и управление собственной службой сохраняются. Standard подтверждает ответы проверяемых адресов; видео YouTube, QUIC, WebSocket и голос Discord требуют отдельной ручной проверки. Эффективность на линии Инфолинка и работа службы после перезагрузки пока не подтверждены.

Python для готовой программы не требуется; для окна нужен Microsoft Edge WebView2 Runtime x64. EXE и установщик не подписаны сертификатом издателя. Контрольные суммы публикуются в `SHA256SUMS.txt`. Лицензия оболочки — MIT, лицензии сторонних компонентов сохранены в поставке.
