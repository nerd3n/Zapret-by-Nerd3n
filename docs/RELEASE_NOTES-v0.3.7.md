# zapret by nerd3n 0.3.7

Предварительный выпуск для Windows 10/11 x64. Улучшена диагностика немедленного завершения сеансового `winws`.

- Сообщение об ошибке включает код выхода и последний фрагмент вывода именно завершившегося процесса.
- Сведения сохраняются в `data/last-startup-failure.json` рядом с EXE: версия, стратегия, PID, код выхода, рабочая папка, аргументы и ограниченный фрагмент вывода. Указывается, был ли вывод усечён и завершилось ли его чтение.
- Файл остаётся после закрытия окна и заменяется при следующем таком сбое. Если сохранить его не удалось, сообщение сообщает об этом, сохраняя исходную ошибку запуска.

Пользователь сообщил завершение `winws` с кодом 2. Прежний вывод процесса не сохранился, а причина пока не воспроизведена. **Этот выпуск улучшает сбор диагностики; исправление причины кода 2 не заявляется.**

Если сбой повторится, сохраните полный текст ошибки и приложите `data/last-startup-failure.json`, указав выбранную стратегию. Перед отправкой просмотрите локальные пути и вывод в файле.

При разборе сообщения отдельно проверены 56 запусков `--dry-run`: все 28 наборов аргументов установленного комплекта и все 28 наборов отдельной распакованной копии завершились с кодом 0. Проверены открытие и закрытие WinDivert с фильтром `false` в режиме sniff, а также два запуска ALT11 с фильтром, не выбирающим пакеты: оба процесса работали 3 секунды до завершения теста. Эти проверки не воспроизводят запуск проблемного сеанса и не подтверждают обход DPI.

Из 309 Python-тестов прошли 305, четыре пропущены из-за ограничения Windows на символические ссылки. Результаты проверки готовой сборки и ограничения публикуются в [VERIFICATION.md](../VERIFICATION.md).

Сохраняется поставка отдельным EXE из 0.3.6: движок, стратегии, списки, профили и лицензии извлекаются рядом с приложением, а существующие файлы не перезаписываются. Установщик, portable ZIP, архив исходников и контрольные суммы остаются вариантами поставки. Для окна нужен WebView2 Runtime x64; Python для готового EXE не требуется. Запуск движка требует прав администратора.

Эффективность стратегий на линии Инфолинка и автозапуск службы после перезагрузки здесь не подтверждаются. EXE и установщик не подписаны сертификатом издателя; контрольные суммы — в `SHA256SUMS.txt`.
