# Установщик zapret by nerd3n

`ZapretByNerd3n.iss` собирает установщик версии 0.2.0 для текущего пользователя Windows 10/11 x64.
ARM64 исключён: поставляемый драйвер WinDivert64.sys требует x64. По умолчанию
приложение устанавливается в `%LOCALAPPDATA%\ZapretByNerd3n`; папка показывается
перед установкой и может быть изменена. Создаётся ярлык в меню «Пуск», ярлык
на рабочем столе предлагается отдельно. Windows получает обычную запись
для удаления приложения.

После установки по умолчанию запускается `ZapretByNerd3n.exe --auto` с запросом
повышенных прав Windows. Отмена UAC оставляет установленное приложение:
его можно открыть позднее через ярлык. Ярлыки используют `--auto --elevate`.
Приложение само определяет, требуется ли первоначальный подбор, и не запускает
его повторно после завершения. При тихой установке приложение не запускается.
Установщик не создаёт системную службу или автозапуск при входе в Windows.

Движок zapret, стратегии, списки и профиль `profiles/infolink-shchelkovo.json`
всегда включены в установщик. Приложение использует папку `bundle` рядом с EXE;
выбирать или скачивать отдельный комплект для первого запуска не требуется.

При повторной установке сохраняются пользовательские списки, результаты,
настройки и выбранные `ACTIVE_*.bin`. Удаление убирает установленные файлы
программы и ярлыки; созданные пользователем данные остаются. Перед удалением
нужно завершить приложение и запущенную им стратегию через интерфейс.

## Сборка

Сначала соберите `ZapretByNerd3n.exe` рядом с `bundle`, `profiles`, `README.md`,
`LICENSE`, `THIRD_PARTY.md`, `GSAP-LICENSE.txt`, `PYTHON-LICENSE.txt`,
`VERIFICATION.md` и папкой `docs` с инструкцией по выпуску.
Затем выполните PowerShell-команду:

```powershell
.\installer\build-installer.ps1 -CompilerPath 'C:\Tools\Inno Setup\ISCC.exe'
```

Дополнительные параметры: `-AppDir`, `-OutputDir`, `-Version`. Можно также
задать путь к компилятору переменной `ZAPRET_ISCC`. Результат по умолчанию:
`dist\Zapret-by-nerd3n-Setup.exe` и контрольная сумма `.sha256`. Данные тестирования,
настройки сборщика и Python-исходники в установщик не включаются. Веб-интерфейс
должен быть встроен в EXE при его сборке.

MIT-лицензия приложения принадлежит nerd3n. Лицензии движка и зависимостей
сохраняются отдельно. Исходный код приложения поставляется отдельным ZIP-архивом;
этот скрипт собирает установщик готовых бинарников.

Версия 0.2.0 проверена с официальным Inno Setup 6.7.3. Его установочный файл
[из официального релиза](https://github.com/jrsoftware/issrc/releases/tag/is-6_7_3)
имеет SHA-256 `9c73c3bae7ed48d44112a0f48e66742c00090bdb5bef71d9d3c056c66e97b732`;
цифровая подпись проверена, издатель Pyrsys B.V. Режим `/PORTABLE=1`
описан в [исходниках Inno Setup](https://github.com/jrsoftware/issrc/blob/is-6_7_3/isportable.iss).

Сборка установщика не выполняет установку приложения и не запускает `winws`.
Готовый установщик этого проекта не имеет коммерческой цифровой подписи.
