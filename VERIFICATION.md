# Проверка zapret by nerd3n 0.2.0

Дата: 21 сентября 2026 года. Проверка приложения и проверка эффективности обхода в сети провайдера разделены.

## Пройдено

- 72 автоматических теста: 71 успешно, 1 пропущен из-за отсутствия прав Windows на создание символической ссылки.
- Импорт всех 22 исходных стратегий и генерация 6 вариантов. Все использованные имена параметров сверены со справкой поставленного бинарника; изменяемые значения также сверены с исходниками движка.
- Передача всех 28 наборов аргументов через Windows subprocess без изменения границ аргументов, включая пути с пробелами и кириллицей.
- Отмена перебора, исключение неполных результатов, смена сети, независимая перепроверка кандидата, восстановление предыдущего состояния и откат при ошибке сохранения.
- Проверка локального API: ограничения адреса и источника запроса, токен для изменений, защита путей отчёта.
- Windows Job Object: закрытие объекта остановило назначенный тестовый процесс, другой тестовый процесс продолжил работу. Это проверялось на безвредных Python-процессах.
- Пять настоящих HTTPS-проверок среды сборки прошли. В ней уже работал сторонний winws, поэтому это не baseline и не подтверждение работы новых стратегий. Локальный отчёт этой среды не включён в публичную поставку.
- Автоопределение фактически получило оператора внешнего IP. Полный IP не попадает в состояние и отчёт.
- Интерфейс проверен в браузере: навигация, поиск, выбор групп 22/6, параметры стратегии, определение сети, настройки, две темы и адаптивная компоновка. Ошибок JavaScript не обнаружено.
- Готовый ZapretByNerd3n.exe запущен без Python из другой рабочей папки: API ответил, 28 стратегий найдены, путь к bundle определён относительно EXE, все 5 ресурсов интерфейса отданы, штатное завершение прошло с кодом 0.
- Финальный установщик с настоящим EXE успешно собран Inno Setup 6.7.3.
- Подпись WinDivert64.sys: Windows Get-AuthenticodeSignature вернул `Valid`.

## Не проверено на целевой линии

На линии **Инфолинк, Щёлково** измерений пока нет. Доступная среда определилась как другой оператор внешнего IP. Запуск winws требует повышения прав, а на этом ПК уже есть отдельный процесс winws; он оставлен работающим.

Автоматические тесты логики используют подставные процессы и измерения там, где требуется перехват трафика. Они не доказывают, что конкретная стратегия обходит DPI. Загрузка WinDivert из новой оболочки, YouTube-видео, QUIC, Discord WebSocket и голос требуют проверки на реальном подключении после установки.

Установщик проверяется компиляцией. Реальная установка и удаление приложения на этом ПК не выполнялись.
